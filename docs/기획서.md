# 기획서 — 운전 MBTI

> 접수양식(DOCX)에 옮겨 적는 원고. [가정] 표시 숫자는 근거 자료로 바꿀 것.

## 1. 앱 개요
- **앱 이름:** 운전 MBTI
- **한 줄 소개:** 차가 본 진짜 내 운전 습관 — 운전 데이터로 만드는 16가지 운전 성격 카드
- **카테고리:** 라이프스타일 (주행 중에는 "기록 중" 한 줄만 표시)
- **대상:** 자기 운전 습관이 궁금한 운전자, 초보 운전자(첫 경험 배지), SNS 공유를 즐기는 20~30대

## 2. 문제
- 운전 습관은 스스로 알기 어렵고, 기존 "안전운전 점수"는 감점 위주라 재미가 없어 금방 안 본다.
- 휴대폰 앱은 가속도·GPS로 추정할 뿐 깜빡이·브레이크·크루즈 같은 실제 조작을 모른다.

## 3. 해결
- 차량 데이터로 4가지 축을 재서 **평가가 아닌 "성격"으로** 보여 준다 (MBTI처럼 16유형, 동물 캐릭터)
  - 운전 리듬(S/D): 브레이크·급가속 빈도 / 깜빡이 습관(C/F): 꺾기 3초 전 방향지시등 비율 / 운전 보조(A/M): 크루즈 사용 비율 / 시간대(L/N): 야간 주행 비율
- 강점 한 줄 + 조언 한 줄 → 잔소리 대신 재미있는 개선 동기
- 첫 고속도로·첫 빗길·첫 야간 등 **첫 경험 배지**로 초보 운전자 성장 기록
- 카드는 SNS 공유용 디자인 (숏폼 바이럴)

## 4. 차량특화성
| 축 | 휴대폰 | 운전 MBTI |
|---|---|---|
| 깜빡이 습관 | 알 수 없음 | 방향지시등 + 핸들 각도 |
| 크루즈 사용 | 알 수 없음 | 크루즈(ADAS) 상태 |
| 급제동 | 가속도 센서 추정(폰 흔들림 오차) | 브레이크 페달 실제 입력 |
| 빗길 배지 | 날씨 API 추정 | 와이퍼 작동 |

## 5. SDK 활용
Vehicle – Gear, Brake, SteeringWheel, TurnSignal, DrivingMode(크루즈), Odometer, Seat(동승), Wiper / AAOS PERF_VEHICLE_SPEED(차속)

## 6. 화면
- **주행 중:** "운전 습관 기록 중 · 12.4 km" + 배지 획득 알림 한 줄 (조작 없음)
- **정차(P):** 성격 카드(이모지·코드·이름·강점·조언), 4축 막대, 배지 8칸, 누적 기록

## 7. 사업성
- **MAU 추정:** Pleos 탑재 차량 [가정] 10만 대 × 앱 설치율 [가정] 25% × 월 활성 [가정] 50% ≈ 1.25만 MAU
- **리텐션:** 매달 새 카드(지난달과 비교), 배지 수집, 습관 변화 그래프
- **바이럴:** 카드 공유 → 공모전 숏폼·SNS 확산, 친구·가족끼리 유형 비교
- **수익 모델:** ① 보험사 제휴 — 동의한 사용자의 "부드러움·신중" 점수로 운전습관 연계 할인 ② 운전 연수·초보 운전 프로그램 제휴 ③ 프리미엄 카드 테마
- **확장:** 동승자 시점 "승차감 점수", 가족 운전자별 비교, 연말 "올해의 운전 리포트"
